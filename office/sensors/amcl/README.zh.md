# AMCL 办公室定位接入

现场请求：改用 AMCL，自主定位和重定位，避免反复询问位置、朝向；不自动移动机器人。

## 查到的掉线原因

- 上一传感器会话的 relay.log 报 `cloud sensor backlog grew 0.912s`，转发退出后监督器重建了 FAST-LIO 会话；旧地图变换不能跨会话复用。
- 旧地图匹配在近期点云一次检验不通过时清空变换，随后全局搜索常因办公室相似结构产生多个候选，长期停在 matching。
- 早先修复过的 DDS 共享内存满问题本次未复现；检查时为约 24/64 MiB。

## 现在运行的组件

官方 ROS 2 Humble nav2_amcl，独立 ROS_DOMAIN_ID=78、ROS_LOCALHOST_ONLY=1；FAST-LIO 保持原 domain 77。AMCL 侧使用本机 UDP，避免与传感器监督器清理 SHM 发生冲突。

adapter.py 只读 raw-state.json/clouds.npz；发布办公室 OccupancyGrid、0.5° LaserScan、hb_amcl_odom→hb_amcl_base 的平面 TF。地面以上 0.15–1.80 m、机身 0.42 m、最远 12 m 的切片规则保留。地图来自修正后的 real-office-navigation.npz，左侧凸起的删除保留。办公室之外设置 unknown，仅用于定位搜索地图，不改真实导航占据图。

seed.py 自动搜索历史三维点云，比较所有精化后的不同位姿假设，为 AMCL 提供唯一性检查通过的初始化位置。不使用操作者提供的“西南朝东”作为初始化约束。该描述只用于核对结果。

这不是完整 Nav2 导航控制部署。无速度发布者、导航动作、机器人模式切换、腿使能或舞蹈程序访问。

## 输出条件

- 原有传感器新鲜度、积压、时间戳、坐标系和会话检查仍生效。
- AMCL 平移方差 ≤0.04 m²、朝向标准差 ≤12°，主粒子簇质量 ≥90%，连续三次稳定候选。
- 至少60条有效激光束、二维匹配中位误差 ≤0.16 m；通常要求0.2 m内吻合比例≥65%。
- 二维地图对当前高度切片覆盖不足时，只在二维吻合≥55%，并且当前三维验证同时达到吻合≥65%、中位误差≤0.12 m、截断平均误差≤0.18 m时接受。
- 所有输出另需三维验证：至少100结构点、吻合≥55%、中位误差≤0.16 m、截断平均误差≤0.20 m。
- 自动初始化另需精化候选中位误差≤0.12 m、吻合≥60%，且不同候选的平均误差差距≥0.05 m，同时通过独立近期点云核验。与旧 ICP 使用不同的组合判据，不能把两者吻合比例直接等同。
- 单帧候选被拒绝时，最多3秒沿最后验证的地图变换、结合**当前**里程计继续跟踪；每次输出必须用0.8秒内的当前点云重新验证几何，并随时间增加不确定度。会话变化、真实传感器失联、几何不符或超过时间界限均不输出可导航坐标。
- 粒子云是滤波器诊断量，静止时可能不更新；不将其年龄误作雷达中断。只保留当前滤波器代次的粒子，并按实时里程计传播后检查质量；重新初始化会清空。

## 启动及维护

3090：

```bash
bash ${HB_OFFICE_ROOT}/start-office-readonly-localization.sh
```

publish-live-state 文件存在时，上述入口转到 AMCL。service.py 同步权威地图；地图变化时先锁定 STOP，停止 AMCL 子进程组，更新地图，再启动。缺少顶层离线 floor 报告时使用随接入包保存的报告。

run.sh 监督 AMCL、文件适配器和自动初始化进程，子进程退出会重新启动该组；不重启机器人或主动移动。传感器容器的下次启动也会调用 manage.py 自动拉起 AMCL。传感器会话变化后重新全局定位。

输出：amcl-state.json；生产输出：../runtime/live-readonly/live-state.json；启动、AMCL、适配器、初始化日志分别为 launcher.log/amcl.log/adapter.log/seed.log。activation.json、observation.json 保存切换及观察证据。启动脚本备份位置见 activation.json。

查看器：http://127.0.0.1:8093/；预览与手动执行：http://127.0.0.1:8092/。

## 限制

没有以“永久在线”承诺替代数据有效性。机器人断电、Wi-Fi中断、雷达停止、定位歧义或地图变化过大时，仍可能暂停导航；界面会给出实际原因。已做静止观察、只读路线预览和软件检查，动态真机导航效果须由现场手动验证。名义安装外参仍不是实测标定。
